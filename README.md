# 🪂 空投雷达 Airdrop Radar

自动追踪 **未发币高 TVL 协议**，识别潜在空投机会，每小时云端运行，微信推送 + 网页日报。

## 快速访问

| 入口 | 地址 |
|---|---|
| 📱 网页日报 | https://nngraet.github.io/airdrop-radar/report.html |
| 📱 短网址 | https://nngraet.github.io/airdrop-radar/ |
| 💬 微信推送 | 关注「方糖」公众号（Server酱） |

## 它是怎么工作的

```
GitHub Actions（每小时第 7 分钟）
   ↓
抓取 DefiLlama 全部协议（约 8700 个）
   ↓
筛选：未发币 + TVL ≥ 1000 万美元 + 非 CEX/公链
   ↓
打分排序 → 检测状态变化（TVL 暴涨 / 新审计）
   ↓
① 微信推送（有新增或变化才推，不轰炸）
② 生成日报网页（report.html + index.html 自动发布）
```

## 打分模型（v2）

| 维度 | 分值 | 说明 |
|---|---|---|
| 规模分（倒 U 型） | 0 ~ 4 | TVL 5000万~10亿 最高分；太高（已成熟）或太低（没实力）递减 |
| 新上线加成 | +2 / +1 | ≤180 天 +2；≤365 天 +1 |
| 老项目扣分 | −3 | `listedAt` 缺失 = 老牌项目，兑现概率低 |
| 融资背景 | +2 | 命中 `FUNDED_PROJECTS` 名单（有知名 VC 投资） |
| 审计加成 | +1 | 已通过审计 |
| 无推特扣分 | −1 | 无社交账号，风险高 |
| 主网 Gas 扣分 | −2 | 只在以太坊主网，交互成本高 |

## 文件结构

| 文件 | 作用 |
|---|---|
| `config.py` | **唯一需要改的文件**：黑名单、融资名单、任务规则、筛选阈值 |
| `common.py` | 时区（北京时间）与公共工具 |
| `sources.py` | 数据源抓取 + 打分模型 |
| `airdrop_monitor.py` | 主程序：抓取 → 打分 → 变化检测 → 微信推送 |
| `daily_report.py` | 生成 `report.html`（网页）+ `report.md`（知识库存档） |
| `seen.json` | 状态库（自动维护，勿手改） |
| `.github/workflows/airdrop.yml` | 云端定时任务 |

## 常用调整

编辑 `config.py`（GitHub 网页上可直接改，下次运行生效）：

```python
MIN_TVL_USD = 10_000_000     # 提高门槛减少噪声
TOP_N_PUSH = 5               # 微信单次推送条数
FRESH_DAYS = 30              # 「新上线」判定天数
TVL_SURGE_RATIO = 1.5        # TVL 涨 50% 触发提醒
CHAIN_FOCUS = {"Base"}       # 只关注特定链
BLOCKLIST = {...}            # 屏蔽已发币项目
FUNDED_PROJECTS = {...}      # 有 VC 融资的项目（+2 分）
```

改抓取频率：编辑 `.github/workflows/airdrop.yml` 的 `cron`（UTC 时间，北京时间 = UTC+8）。

## 安全提醒

- 交互一律用**小额专用钱包**，与主资产隔离
- 只从报告的**官网/官推**进入，不点陌生链接
- 授权前核对合约权限，定期用 revoke.cash 清理
- 遵守项目方规则，**不做批量小号女巫攻击**（会被清号、追回）
- 本工具仅供信息参考，**不构成投资建议**

## 排障

| 现象 | 处理 |
|---|---|
| 微信没收到 | Actions → 运行日志搜「推送」，会显示失败原因 |
| 网页 404 | 确认 URL 末尾有 `/report.html`，或 Pages 设置已开启 |
| 数据源暂不可用 | 境外源波动，下周期自愈，无需处理 |
| 想暂停 | Actions → 「空投雷达」→ 右上 `···` → Disable workflow |
